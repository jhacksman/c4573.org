What It Does

Collects property data from 764 Texas data sources — county assessor sites, appraisal districts, tax offices, and public records portals across all 254 counties. Run it as a CLI, deploy with Docker, or query via the built-in REST API.

  • 764 data sources across all 254 TX counties
  • Property address, owner name, mailing address
  • Assessed value, land value, improvement value
  • Tax amount, tax year, exemptions
  • Lot size, square footage, year built, bedrooms, bathrooms
  • Last sale date, last sale price, legal description
  • Output: CSV, JSON, or direct to PostgreSQL

FAQ

Is this legal?

Yes. County assessor data is public record under Texas law. This tool accesses the same data you'd see on the county website.

Why 764 sources for 254 counties?

Many counties have multiple data portals — a central appraisal district, a tax office, and sometimes a separate GIS portal. We scrape all of them and merge the results.

Do I need Docker?

No. Just Docker. One command: docker compose up brings up the engine, database, and web UI.

How long does a full state scrape take?

2-4 hours for all 764 sources across 254 counties, with default rate limiting (1 req/sec per source).

What happens after 12 months?

You keep the code forever. After 12 months, you stop receiving adapter updates when county sites change layouts. You can renew for another $13.37/year, or maintain the adapters yourself.

Do I need an API key?

No. Zero external API dependencies. Everything scrapes public websites directly.

Can I modify the code?

Yes. MIT licensed. Modify it, integrate it into your pipeline, resell it — no restrictions.
