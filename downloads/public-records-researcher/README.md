# Public Records Researcher source

This versioned download contains the reusable research instructions and Python source that accompany the Grok Bot template. Keep an independent copy if you use the tool. The package includes its own file manifest and offline reconstruction steps. It contains no research subjects, output records, datasets, accounts, credentials or private browser sessions.

The template uses free sources. Its business-record workflows include snapshots, browser searches and clearly labeled assisted steps. A name match is a candidate, not an identity conclusion, and a blocked or incomplete search is not proof that no record exists. State workflows do not establish every federal, court, property or county record source.
