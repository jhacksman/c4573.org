# Competitor SEO Analysis

## Competitor Landscape

c4573.org competes in three overlapping markets:
1. **Property data providers** (BatchData, PropStream, ATTOM) — enterprise SaaS
2. **Web scraping tools** (Apify, Scrapy, ScrapingBee) — developer platforms
3. **Indie developer tool shops** (Gumroad creators) — small-scale competitors

We don't compete head-to-head with any of these. Our positioning is unique: a $10 one-time purchase tool that replaces $500/month SaaS subscriptions. The SEO strategy exploits this gap.

---

## Competitor 1: BatchData (batchdata.io)

### Profile
- **Pricing:** $500-$5,000/month, custom enterprise plans up to $100,000+/year
- **Coverage:** 155M+ U.S. properties
- **Domain Authority:** ~45-50
- **Monthly traffic:** ~30,000-50,000 visits (estimated)

### SEO Strengths
- Active blog (2-3 posts/month) targeting "real estate API" and "property data" keywords
- Strong comparison content ("BatchData vs ATTOM," "Top Real Estate APIs")
- API documentation pages that rank for long-tail developer queries
- Product landing pages targeting "skip tracing API," "property data enrichment"

### Keywords They Rank For
| Keyword | Position | Volume |
|---------|----------|--------|
| real estate data api | Top 10 | 1,000+ |
| property data api | Top 10 | 500+ |
| skip tracing api | Top 10 | 300+ |
| batchdata | #1 (branded) | 1,000+ |
| attom data alternative | Top 5 | 100-300 |

### Our Angle Against BatchData
- They cost 50-500x more
- They require API integration (developer overhead)
- They don't offer self-hosted solutions
- **Target keyword:** "batchdata alternative" / "cheap property data"
- **Content play:** "BatchData vs DIY Scraping: When $10 Beats $500/Month"

## Competitor 4: Apify (apify.com)

### Profile
- **Pricing:** $49/month + per-usage, free tier available
- **Coverage:** Marketplace of 3,000+ scrapers (user-created)
- **Domain Authority:** ~70+
- **Monthly traffic:** ~500,000+ visits (estimated)

### SEO Strengths
- Massive marketplace creates thousands of indexed pages (one per scraper)
- Each "Actor" page targets long-tail keywords ("texas contractor scraper," "zillow scraper")
- Strong developer blog with scraping tutorials
- High DA from years of backlinks and GitHub presence

### Keywords They Rank For
| Keyword | Position | Volume |
|---------|----------|--------|
| web scraper | Top 10 | 10,000+ |
| apify | #1 (branded) | 8,000+ |
| [site] scraper | Top 5 (many) | varies |
| web scraping tool | Top 10 | 5,000+ |

### Our Angle Against Apify
- Apify charges per-usage (costs scale with data volume)
- Apify scrapers are platform-dependent (can't run locally without Apify)
- Apify quality varies (community-created scrapers)
- **Target keyword:** Not directly competing. We target different buyer intent.
- **Content play:** Position as "buy once, run forever" vs. "pay per scrape"

## Competitor 5: PublicData.com

### Profile
- **Pricing:** $17.50-$92/month
- **Coverage:** Texas property records, court records
- **Domain Authority:** ~35-40
- **Monthly traffic:** ~10,000-20,000 visits (estimated)

### SEO Strengths
- Ranks for "texas public records" (long-standing domain)
- Simple site, fast loading
- Very focused niche (Texas + a few other states)

### Weaknesses We Can Exploit
- Dated website design (looks like 2005)
- No technical content or blog
- Per-lookup pricing model (600 lookups for $17.50/mo)
- No bulk export or API
- **Target keyword:** "publicdata.com alternative" / "texas public records bulk download"
- **Content play:** "PublicData.com Charges Per Lookup. Here's How to Get Unlimited Texas Data for $10."
