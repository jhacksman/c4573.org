## Content Production Notes

- **No AI slop.** Write with specific technical detail and real data. Google penalizes thin AI content.
- **Show terminal output.** Every blog post should include at least one code snippet or CLI screenshot.
- **Lead with the problem.** "Tired of paying $500/month?" converts better than "Introducing our Python scraper."
- **Include comparison tables.** Tables rank well in featured snippets and are scannable.
- **Internal linking.** Every blog post links to the product page. Every county page links to the main product page.
- **Update dates.** Keep "2026" in titles. Google favors recent content for tool comparisons.
