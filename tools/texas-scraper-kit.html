What It Does

Scrapes all 254 Texas county assessor websites and outputs structured property data:

  • Property address, owner name, mailing address
  • Assessed value, land value, improvement value

  • Last sale date, last sale price

FAQ

Is this legal?

Yes. County assessor data is public record by law. This tool accesses the same data you'd see on the county website.

How long does a full state scrape take?

2-4 hours for all 254 counties, depending on your connection and rate limiting settings.

Do I need an API key?

No. Zero external dependencies. Just Python and the included requirements.

What if a county site changes?

The script handles failures gracefully and skips broken counties with a summary report. We update adapters monthly.

Can I modify the code?

Yes. MIT licensed. You own it, can modify it, can resell it.
